# 设置、应用壳与统计规格

本文件描述本地应用的非学习核心能力：设置持久化、配置导入导出、应用壳状态、更新提示、静态入口和统计页管理交互。

## 设置存储与 API

- **AC-SET-001-01**：设置按 namespace/key 存储；单项写入后可读取，缺失项返回空语义。
- **AC-SET-001-02**：同一 namespace 下可批量写入和读取；读取全部设置时必须按 namespace 分组。
- **AC-SET-001-03**：删除 namespace 或清空全部设置时，应返回删除数量；删除空目标应安全返回 0。
- **AC-SET-001-04**：设置 API 应支持读取全部、写入单项、批量写入、读取 namespace、清空全部，并拒绝空字符串值。

## 设置导入导出与语言

- **AC-SET-002-01**：前端导出设置时必须排除 provider API key；如果某 namespace 只剩敏感字段，则整个 namespace 不导出。
- **AC-SET-002-02**：前端导入设置时应合并合法字符串值，跳过 API key、非字符串值和非对象 namespace。
- **AC-SET-002-03**：用户切换界面语言后应持久化 locale，并更新当前缓存的阅读界面文案。

## 阅读显示设置

- **AC-SET-003-01**：阅读内联设置可以修改主题等显示偏好，并同步到本地缓存。
- **AC-SET-003-02**：点击阅读设置空白遮罩应关闭设置面板，不改变阅读内容。

## 应用壳与静态入口

- **AC-SHELL-001-01**：健康检查 API 应返回后端可用状态。
- **AC-SHELL-001-02**：生产静态路由应把未知前端路径回退到 `index.html`。
- **AC-SHELL-002-01**：当后端报告有新版本时，应用应延迟显示更新提示；无更新时不显示提示。
- **AC-SHELL-002-02**：用户关闭更新提示后，当前会话不应继续展示该提示。

## 统计页交互

- **AC-STATS-001-01**：统计页的危险删除操作应与行内编辑入口分离，避免误删。

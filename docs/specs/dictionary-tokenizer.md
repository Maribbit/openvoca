# 词典、分词与词元规格

本文件描述阅读文本如何被拆成可学习 token，以及词典查询、词元修正和文本还原如何保持一致。

## 词典查询

- **AC-DICT-001-01**：内置 ECDICT 查询应大小写不敏感；已知词返回词条，未知词返回空结果。
- **AC-DICT-001-02**：词典查询逻辑应允许对自定义 SQLite 词典文件执行同样的查找。
- **AC-DICT-001-03**：词典 API 对已知词返回定义、音标和翻译；未知词返回 404。

## 阅读分词与目标标记

- **AC-TOK-001-01**：普通句子应被 spaCy 分词，并为可学习词提供词性和词元。
- **AC-TOK-001-02**：单星号或模型偶发的双星号 Markdown 标记应被识别为目标词，输出 token 中不应残留星号。
- **AC-TOK-001-03**：被显式标记为目标词的 stopword 必须保持可点击。
- **AC-TOK-001-04**：空句子或纯空白输入应返回空 token 列表。

## 空格、缩写与连字符

- **AC-TOK-002-01**：缩写分词必须保留正确的 `trailingSpace`，避免还原文本时出现多余空格。
- **AC-TOK-002-02**：目标词和非目标词中的连字符复合词都应合并为单个 token，多段连字符也应保留。
- **AC-TOK-002-03**：前端把 token 还原为纯文本时，应遵循 `trailingSpace`，正确处理标点、缩写和连字符。

## 词性过滤与歧义词

- **AC-TOK-003-01**：`well`、`can`、`will` 等歧义词作为名词时应可点击，作为助动词或功能词时应过滤。
- **AC-TOK-003-02**：代词、限定词、介词和连词等功能词默认不作为可学习词。

## 词元与修正

- **AC-TOK-004-01**：所有字母词应带有 spaCy lemma；非字母 token 不需要 lemma。
- **AC-TOK-004-02**：以双 `s` 结尾的词不能被错误地去复数化。
- **AC-TOK-005-01**：前端词元修正输入应规范化大小写和空白，只允许单个合法词元。
- **AC-TOK-005-02**：当前句子的词元修正只在本轮生效，并支持从定义浮层到进度弹窗的连续修正。

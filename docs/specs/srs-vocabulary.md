# SRS 与词库规格

本文件描述本地词库记录、间隔重复算法、人工管理和导入导出行为。这里的词库是单机本地数据，不涉及用户账户或多词库隔离。

## 熟悉度变化

- **AC-SRS-001-01**：目标词未被标记为不认识时应提升熟悉度；被标记为不认识时应降低或保持在最低熟悉度。
- **AC-SRS-001-02**：熟悉度必须被限制在最小值和最大值之间。
- **AC-SRS-001-03**：已毕业词被再次标记为不认识时，应回到可复习队列并设置新的 cooldown。

## 冷却队列与选词

- **AC-SRS-002-01**：每次推进学习轮次时，所有大于 0 的 cooldown 都应递减。
- **AC-SRS-002-02**：cooldown 不能低于 0；仍在 cooldown 中的词不能被选为目标词。
- **AC-SRS-002-03**：熟悉度达到毕业等级的词不能继续被选为目标词。
- **AC-SRS-002-04**：目标词选择应优先返回熟悉度较低、已到期的词。

## 完整轮次与原始目标词安全网

- **AC-SRS-003-01**：连续学习轮次中，被认识的词应推迟复现，被标记不认识的词应更快复现。
- **AC-SRS-004-01**：如果 tokenizer 未能把原始目标词匹配到结果文本，`original_targets` 仍应让该词按认识处理推进。
- **AC-SRS-004-02**：如果原始目标词已经通过 target words 处理过，不能被重复推进。
- **AC-SRS-004-03**：如果原始目标词被用户标记为不认识，不能按安全网推进。

## 词条记录元数据

- **AC-SRS-005-01**：新词记录应保存首次出现时间、最近出现时间、出现次数和最近上下文。
- **AC-SRS-005-02**：用户标记的非目标词也应进入词库，并按“不认识”规则初始化。

## 人工管理

- **AC-SRS-006-01**：用户可以清空全部词条，系统返回删除数量。
- **AC-SRS-006-02**：用户可以手动修改单词熟悉度和 cooldown，输入值必须被限制在有效范围内。
- **AC-SRS-006-03**：修改不存在或已被其他标签页删除的词条时，应返回未找到语义。
- **AC-SRS-006-04**：用户可以删除单个词条；重复删除不存在的词条应返回未找到语义。

## 本地数据位置

- **AC-SRS-007-01**：默认数据库路径应指向本地 `openvoca.db`；设置 `OPENVOCA_DATA_DIR` 后应改用指定目录。

## CSV 导入导出

- **AC-SRS-008-01**：导出 CSV 必须包含稳定表头；空词库也应导出只有表头的文件。
- **AC-SRS-008-02**：导入 CSV 能创建新词；只提供 `lemma` 时应使用安全默认值。
- **AC-SRS-008-03**：导入默认使用 skip 模式保留已有词；overwrite 模式允许覆盖已有词。
- **AC-SRS-008-04**：导入缺少字段、空 lemma、非整数、过大文件或非 UTF-8 内容时，应跳过或拒绝并报告错误。
- **AC-SRS-008-05**：导入时应规范化大小写、兼容旧 `pos` 列、接受 UTF-8 BOM，并保留合法时间戳与上下文。
- **AC-SRS-008-06**：导出的 CSV 再导入后，熟悉度、cooldown、上下文、出现次数和时间戳不能丢失。

## 词库列表与统计

- **AC-SRS-009-01**：词库列表 API 必须返回 lemma、level、cooldown、lastSeen 等学习状态字段。
- **AC-SRS-009-02**：词库列表应支持按到期、熟悉度和最近出现排序；非法排序参数应被拒绝。
- **AC-SRS-010-01**：反馈预览应能计算每个词的旧等级、新等级和新词状态，但不直接提交变更。
